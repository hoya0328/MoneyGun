# Signal Guild 로드맵

최종 갱신: 2026-09-07

## 로드맵 원칙

- 한국 주식과 미국 주식을 순차적으로 검증하며, 한 번에 한 신규 시장과 한 전략군만 승격한다.
- 수익 기능보다 데이터 시점, 감사 기록, 위험 통제를 먼저 만든다.
- 자동화 수준은 `연구 → 5만 원 L0 초소액 실거래+동시 그림자 → 10만 원 승인형 → 제한적 자율 → 정상 자율` 순으로만 높인다.
- 다음 단계 승격은 일정이 아니라 측정된 품질 게이트로 결정한다.

- [x] 시장별·통합 벤치마크 초안 선택
- [x] 10만 원 집중투자 미션과 모드별 최대 낙폭·손실·집중 한도 정의
- [x] 단계별 위험 위임장 기본값 설정
- [ ] 신한은행 연계 키움 계좌의 HTS ID·해외주식·API 등록 가능 여부 확인
- [x] 허용 종목·금지 종목·최소 유동성 기본값 결정
- [x] 종가후 신호, 다음 세션 주문, 5~20일 보유와 청산 조건 정의
- [x] 공식 데이터 출처와 기준 시각 기본값 정의
- [x] 백테스트·워크포워드·그림자·실거래 승격 기준 정의

완료 게이트: 계좌 적격성 확인과 사용자 지정 실거래 자본 입력을 제외한 기계 검사 가능 투자 위임장 초안이 준비된다.

완료 게이트: 종가 전략 하나가 동일 데이터에서 재현되고, 누출 검사와 비용 포함 OOS 검증 결과를 낸다.

현재 상태: 엔진과 실패 폐쇄 게이트는 완료했다. 실제 권한 데이터 번들과 100거래 이상 결과가 없어 1단계 완료 게이트와 R1 승격은 아직 미통과다.

- [x] 작전실·투자위원회·직원 사무실·주문·감사 화면 프로토타입

P3 개발 상태: 20거래일 `REPLAY` 패키지 20/20, 날짜별 잠금·재시도, 9명 점수판과 작전실 브리핑은 완료했다. 실제 데이터로 경과한 운영일은 0일이므로 위 완료 게이트는 아직 통과하지 않았다.

## 3단계 — 자동 그림자 운용

목표: 실시간 시장에서 실제 주문만 보내지 않고 결정에서 체결·잔고·성과 귀속까지 전 과정을 자동화한다.

- [x] 최신 위원회 결정에서 다음 세션 그림자 주문 생성
- [x] 주문 멱등성·중복 방지와 append-only 가상 체결 이벤트
- [x] 공식 시세 기준 그림자 체결과 키움 계좌 잔고 대사 소프트웨어
- [x] 포트폴리오 한도와 서버 킬 스위치 소프트웨어
- [x] 그림자 주문 상태·체결·취소 운영 귀속 요약

- [x] 별도 규칙 버전의 챔피언/챌린저 동시 OOS 비교
- [x] 지연 호가·대사 불일치·중복 의도·UNKNOWN 주문 금지 훈련

완료 게이트: 그림자 원장은 L0 실거래와 같은 신호로 계속 누적한다. 60거래일은 더 이상 최초 실주문을 막는 대기 기간이 아니라 v2 생성과 자본·자율성 승급을 평가하는 관측 기간이다.

### 3A — 한국 주식 선행 게이트

- 한국 주식만 활성화하고 미국 주식은 분석·데이터 수집만 수행한다.
- 20거래일 연속 데이터 시점, 신호 재현, 주문 대사, 위험 위반이 모두 통과하면 미국 연구·그림자 슬리브를 준비할 수 있다. 미국 실주문은 한국 L2 전에는 금지한다.

### 3B — 미국 주식 추가 게이트

- 한국 슬리브의 규칙을 복사하지 않고 거래시간, 통화, 휴장, 주문 유형, 세금·수수료를 독립 설정한다.
- 원화와 달러 기준 손익을 함께 기록하고 주식 알파와 환율 효과를 분리한다.

## 5단계 — 5만 원 초소액 실거래 L0와 60일 학습 루프

목표: 한국 주식에서 손실 가능액을 5만 원으로 격리하고 실제 주문·체결·평가손익을 관찰하면서 동일 신호 그림자 결과와 비교한다.

- [x] 대상 증권사 공식 주문·미체결·체결 API 사양 재검토
- [x] 키움 조회 전용 OAuth·국내 계좌평가잔고 어댑터와 마스킹 스냅샷 기반
- [x] 실계좌 잔고와 Signal Guild 미션 자본 대사 로직
- [x] 조회·주문 자격증명 분리와 주문 전용 프로세스 경계
- [x] 기존 10만 원 미션과 분리된 5만 원 L0 자본 원장·브로커 잔고 대사
- [x] 최대 주문예산 45,000원·동시 1종목·하루 신규 3건·일손실 1,500원·누적손실 5,000원 강제
- [x] 모든 분석·토론·모드·매수·매도 기능을 열되 하나의 자본 조정자와 Execution Guardian만 실주문 제출
- [x] 실주문 의도가 원본 공식 그림자 주문을 참조하고 미실행·거절 이유와 실제 체결을 분리 기록
- [x] 15실거래일 단위 v1.1~v1.n 동결 리뷰와 버전별 성과 분리
- [x] 60실거래일 종료 시 v2 후보 보고서 생성; 자동 적용·자동 증액 금지
- [x] 지연·대사 불일치·중복·UNKNOWN 무재시도 훈련
- [x] 로컬 관측성·알림·온라인 백업·격리 복구·감사 무결성 게이트
- [x] 부분 체결·실브로커 네트워크 단절의 결정론적 통합 훈련
- [x] `DESKTOP_LIVE` 자동 시작·SQLite 단일 작성자·Windows 비밀 저장소·단일 Guardian·복구/백업 소프트웨어
- [ ] 대상 PC의 DPAPI 비밀·예약 작업·절전/시각·IP·백업 암호화와 복구 훈련 증거

진입 게이트: 전략 수익성 OOS 통과는 L0 시작의 필수조건이 아니지만, 유효한 결정론적 전략·공식 시세·실계좌 대사·주문 멱등성·킬 스위치·운영 보안·별도 `릴리스 점검`·사용자 활성화 승인은 모두 필수다.

완료 게이트: 60실거래일 동안 중대 사고 0건, 대사 100%, 버전별 실제 비용·슬리피지·손익·낙폭 보고가 완성되고 v2 후보와 10만 원 L1 승급 여부를 사용자가 결정한다.

## 6단계 — 제한적 자율 실거래 L2

목표: 승인된 FOCUS-MOMENTUM-KR v1과 종목군 안에서 사용자 개별 승인을 받지 않고 자동 매수·매도한다.

- [x] 집중투자 총노출 100%·최대 3종목·거래당 위험 5%·열린 위험 15% 강제
- [x] 목표 사다리와 실현이익 20% 금고 잠금
- [ ] 신규 매수 계획 사전 브리핑과 체결 후 즉시 알림
- [x] 서버 킬 스위치와 대사·위험·중복·중대사고 자동 강등
