# MoneyGun 초기 위험 위임장

최종 갱신: 2026-09-03
상태: **기본안 v0.5 — L0-AUTO-v1 위임 자동 실행과 5만 원 손실 경계 결합**

## 적용 목적

이 문서는 수익 목표가 아니라 시스템 오류, 집중, 갭, 과도한 회전과 연속 손실을 제한하기 위한 안전 계약이다. 사용자의 요청에 따라 기본값을 먼저 정하되, 실제 투자 가능 자본·소득·부채·비상자금·손실 감내도가 입력되기 전에는 L1 승인 자본 상한을 넘지 않는다.

## 자본과 시장 배분

| 항목 | 제안 기본값 | 해석 |
|---|---:|---|
| 초기 연구·그림자 기준 자본 | 100,000원 | 첫 집중투자 미션과 같은 자본으로 비용·수량 제약 검증 |
| L0 초소액 실거래 자본 | `min(계좌 예수금, 사용자 승인금액, 50,000원)` | 추가입금 없이 별도 미션 원장으로 격리 |
| 초기 집중투자 미션 자본 | `min(계좌 예수금, 사용자 승인금액, 100,000원)` | 추가입금 없이 독립 미션으로 시작 |
| 안전투자 총 주식 노출 | 순자산의 최대 60% | 후속 BALANCED 모드 기본값 |
| 장기투자 총 주식 노출 | 순자산의 최대 80% | 후속 LONG_TERM 모드 기본값 |
| 장기 확장 목표 배분 | 한국 56%, 미국 24%, 현금 20% | 여러 모드·시장 검증 후에만 적용 |
| 미국 슬리브 상한 | 순자산의 30% | 한국 L2 전에는 실주문 비활성 |
| 통합 외화 노출 | 순자산의 최대 30% | 환헤지를 기본 가정하지 않고 환율 손익을 분리 기록 |

확장 목표는 강제 매일 리밸런싱하는 값이 아니다. 각 미션의 모드 한도 안에서 신규 주문을 제한하는 기준이다.

기존 표의 정상 배분은 안전투자 모드의 장기 확장 기준이다. 초기 집중투자 미션에는 [MODE_PROFILES.md](./MODE_PROFILES.md)의 1~3종목, 총노출 100%, 거래당 위험 5%, 미션 낙폭 -30% 중지 기준을 적용한다. L1에서는 모드와 관계없이 총노출을 50%로 제한한다. 권한 단계와 모드 중 더 엄격한 값이 항상 우선한다.

L0에서는 모든 모드의 분석·토론·주문 후보 기능을 사용할 수 있지만 실제 자본은 하나의 조정자가 배분한다. 실제 주문은 최대 45,000원, 동시 1종목, 하루 신규 진입 3건으로 제한한다. 당일 실현·미실현 합계가 -1,500원에 도달하면 당일 신규 진입을 중지하고, 파일럿 최고자산 또는 최초 50,000원 기준 누적 손실이 5,000원에 도달하면 L0를 중지한다. 수익으로 평가액이 50,000원을 넘어도 신규 실투입 한도는 50,000원이며 자동 추가입금은 금지한다.

`L0-AUTO-v1`은 위 수치와 차단 조건을 변경하지 않고 주문별 클릭만 Execution Guardian에
위임한다. 활성화 이후 생성된 주문 의도만 자동 처리하고, 기존 외부 보유종목은 계속 수량·손익·
청산 대상에서 제외한다. 공식 공시 감시가 READY가 아니거나 위험 공시가 활성인 신규 BUY,
상태가 불명확한 주문, 대사 차이와 오래된 호가는 자동화 여부와 관계없이 실패 폐쇄한다.

## 포지션과 집중도

집중투자 모드의 활성 기준은 다음과 같다.

| 항목 | FOCUS 기본값 |
|---|---:|
| 보유 종목 | 1~3종목 |
| 단일 종목 | 최대 50% |
| 거래당 계획손실 | 미션 순자산의 최대 5% |
| 모든 보유 포지션 계획손실 | 미션 순자산의 최대 15% |
| 하루 신규 진입 | 최대 1종목 |
| 자동 추가입금 | 금지 |

아래 표는 후속 안전투자 모드의 기본값이다.

| 항목 | 제안 기본값 |
|---|---:|
| 단일 종목 시가평가액 | 순자산의 최대 5% |
| 단일 거래 계획손실 | 순자산의 최대 0.5% |
| 모든 보유 포지션의 계획손실 합계 | 순자산의 최대 2.0% |
| GICS/WICS 단일 섹터 | 순자산의 최대 20% |
| 같은 공급망·고상관 테마 | 순자산의 최대 25% |
| 하루 신규 주식 노출 증가 | 순자산의 최대 10% |
| 하루 매매대금 | 순자산의 최대 20% |

포지션 크기는 다음 두 값 중 작은 값으로 결정한다.

`허용 포지션 비중 = min(단계별 종목 상한, 단계별 거래당 위험 ÷ 진입가 대비 무효화 가격 거리)`

예를 들어 집중투자 L2에서 무효화 가격이 진입가보다 10% 아래이고 거래당 위험이 5%라면 최대 포지션은 미션 순자산의 50%다. L1에서는 권한 단계 총노출 50%와 사용자 승인이 추가로 적용된다. 모든 종목에 같은 고정 손절률을 강제하지 않고 전략 무효화 조건과 변동성을 사용한다.

## 손실 단계와 킬 스위치

### 집중투자 미션

| 조건 | 자동 조치 |
|---|---|
| 당일 미션 수익률 -10% 이하 | 다음 세션 신규 진입 중지 |
| 고점 대비 -20% | 거래당 위험 5%→2.5%, 총노출 50%로 축소 |
| 고점 대비 -30% | 미션 중지, 사용자 재승인 전 재개 금지 |
| 미션 원장 밖 자본 사용 시도 | 주문 거부와 중대 사고 생성 |

### 안전투자 미션

| 조건 | 자동 조치 |
|---|---|
| 당일 순자산 수익률 -2.0% 이하 | 다음 세션 신규 진입 중지, 데이터·주문·시장 이벤트 검토 |
| 최근 5거래일 누적 -4.0% 이하 | 신규 거래 위험과 최대 포지션을 50% 축소 |
| 고점 대비 낙폭 -6.0% | 신규 거래 위험과 총 주식 노출을 50% 축소 |
| 고점 대비 낙폭 -8.0% | 신규 진입 중지, 청산·위험축소 주문만 허용 |
| 고점 대비 낙폭 -12.0% | 해당 안전투자 미션 중지, 사용자 재승인 전 재개 금지 |
| 데이터 신선도 실패·잔고 불일치·중복 주문 의심 | 손익과 무관하게 신규 주문 즉시 금지 |

손실 기준은 미션별 원화 순자산과 통합 원화 순자산에 각각 계산한다. 여러 조건이 동시에 발생하면 더 엄격한 조치를 적용한다. 데이터 신선도 실패·잔고 불일치·중복 주문 의심은 모드와 손익에 관계없이 모든 신규 주문을 즉시 금지한다.

## 체결·유동성 방어선

- 집중투자 한국 종목군: KOSPI·KOSDAQ 보통주 중 20거래일 중앙 일거래대금 50억 원 이상이며 1주 가격이 단일 종목 주문예산 이내.
- 안전투자 한국 종목군: KOSPI 200·KOSDAQ 150 보통주 중 20거래일 중앙 일거래대금 100억 원 이상.
- 미국 초기 종목군: S&P 500·NASDAQ-100 보통주 중 주가 5달러 이상, 20거래일 중앙 일거래대금 2,000만 달러 이상.
- 관리·거래정지·정리매매·SPAC·우선주·OTC·레버리지/인버스 상품은 제외한다.
- 계획 가격 대비 다음 세션 시가 갭이 `3%`와 `1 ATR(14)` 중 큰 값을 넘으면 추격 주문을 취소하고 수량과 무효화 가격을 다시 계산한다.
- 상·하한가, 거래정지, 호가 공백, 데이터 지연 시 체결을 가정하지 않는다.
- 백테스트와 모의운용에는 실제 계좌 수수료·세금·환전 비용과 관측 슬리피지를 반영한다.

## 금지 사항

- 신용·미수·레버리지, 공매도, 옵션·선물·CFD
- 손실 만회 목적의 한도 확대와 물타기
- RISK 거부권을 우회한 수동 또는 AI 주문
- 근거·기준 시각·무효화 조건이 없는 신규 진입
- 같은 신호로 생성된 주문을 여러 에이전트가 중복 제출하는 행위

## 재보정 시점

L0 실거래 단계에서는 매 15실거래일과 모든 중대 사고 직후 다음을 검토한다. 60실거래일에는 v2 후보와 자본·자율성 승급 여부를 별도로 검토한다. L1 이상에서는 매 20거래일 검토를 유지한다.

- 실제 슬리피지와 비용, 갭 손실, 회전율
- 전략별 최대 낙폭과 손실 연속성
- 한국·미국 및 환율 효과별 위험 기여도
- 한도 때문에 막힌 거래와 한도가 방지한 손실

한도 변경은 새 버전으로 제안하고 사용자 승인 후 다음 거래일부터 적용한다. 과거 성과를 좋게 보이게 하기 위한 소급 변경은 금지한다.
