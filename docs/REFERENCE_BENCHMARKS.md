# MoneyGun 외부 레퍼런스 채택 기준

최종 갱신: 2026-08-31

## 목적

유명 투자자, 논문, 오픈소스 에이전트와 자동매매 프레임워크에서 검증 가능한 장점만 가져오고 수익률 주장, 인물 모방 프롬프트, 검증되지 않은 실거래 코드는 그대로 채택하지 않는다.

## 공통 채택 시험

새 레퍼런스, 모델, 직원 또는 지표는 다음 질문을 모두 통과해야 한다.

1. 원문·코드·데이터·시점이 확인되는가?
2. 자연어가 아니라 기계가 재현할 규칙으로 바꿀 수 있는가?
3. 기존 기준선에 더해 OOS 순효과가 있는가?
4. 비용·지연·오류·비결정성을 포함해도 개선되는가?
5. 제거 실험으로 해당 구성요소의 기여를 분리할 수 있는가?
6. 실패할 때 주문을 막거나 안전하게 축소할 수 있는가?

한 항목이라도 답이 아니면 연구 후보로 남기고 운영 전략에 승격하지 않는다.
