# MoneyGun 실거래 운영 기준

최종 갱신: 2026-09-03
상태: 제품 정책 v0.3 — L0-AUTO-v1 소유자 위임 자동 실행 반영

## 목적과 적용 범위

MoneyGun은 최종적으로 소유자 본인의 키움증권 계좌에서 한국·미국 주식을 자동 매매한다. 최초 60거래일을 실주문 금지 기간으로 두는 대신, 기술·보안 릴리스 게이트를 통과하면 수익성 미검증 상태임을 표시하고 5만 원 L0 초소액 실거래와 동일 신호 그림자 운용을 병행한다. 운영 단계는 연구, L0 초소액 실거래, 10만 원 승인형 실거래, 제한적 자율 실거래, 정상 자율 실거래 순서로 올라간다.

- 대상 사용자와 자금: 소유자 1명의 자기자금만
- 대상 상품: 한국·미국 상장 보통주, 롱 포지션만
- 금지 상품: 신용·미수·레버리지, 공매도, 파생상품, CFD, OTC, 암호화폐
- 첫 실거래 시장: 한국 주식
- 첫 증권사: 키움증권 REST API
- 주문 판단 주기: 장 종료 후 일봉 기반 저빈도 스윙
- 실거래 후보 전략: 집중투자 `FOCUS-MOMENTUM-KR-v1`과 독립 챌린저 종가매매 `CLOSE-AUCTION-KR-v2`. 각 전략은 별도 자격을 통과해야 한다.

타인에게 추천을 판매하거나 타인의 계좌·자금을 운용하는 기능은 만들지 않는다. 이 범위가 바뀌면 투자자문·투자일임 관련 법률 검토가 끝날 때까지 기능을 차단한다.

## 실거래 승격 단계

| 단계 | 주문 권한 | 자본·노출 기본값 | 최소 통과 조건 |
|---|---|---|---|
| R0 연구 | 주문 없음 | 과거 데이터만 | 재현 가능한 백테스트와 누출 검사 |
| L0 초소액 파일럿 | 5만 원 한도 실주문과 동일 신호 그림자 쌍. `L0-AUTO-v1` 승인 시 주문별 클릭 위임 가능 | 최대 실투입 5만 원·주문예산 4만5천 원·동시 1종목 | 기술·보안 릴리스 게이트, 공식 시세·대사·뉴스·킬 스위치, 소유자 위임 |
| L1 소액 승인형 | 매수는 사용자 승인, 위험축소 매도는 자동 | 집중투자 미션 10만 원, 총노출 50%, 하루 신규 1건 | 20거래일·20회 실제 체결, 중대 사고 0건, 실제 슬리피지 허용 범위 |
| L2 제한적 자율 | 승인된 전략·종목군 안에서 매수·매도 자동 | 선택 모드의 전체 한도, 집중투자는 총노출 100%·최대 3종목 | 60실거래일·100회 체결, 중대 사고 0건, 순비용 기대값 양수 |
| L3 정상 자율 | 여러 승인 미션·시장 상시 자동 | 모드별 한도, 모드 간 자본 이동은 사용자 승인 | 6개월 이상 L2 기록, 별도 사용자 승인과 재점검 |

단계 변경은 자동으로 일어나지 않는다. 시스템은 승격을 제안할 수 있지만 소유자의 명시적 승인과 새 위임장 버전이 필요하다. 어느 단계에서든 손실·장애 기준을 위반하면 자동 강등한다.

`L0-AUTO-v1`은 단계 승격의 예외가 아니라 5만 원 L0 안에서 주문별 클릭만 위임하는
별도 실행 권한이다. 위임 활성화 뒤 생성된 주문안만 대상으로 하며, 활성화 전 대기 주문은
소급 제출하지 않는다. 전략의 OOS 자격과 L1/L2 확대 조건은 그대로 유지한다.

## 연구에서 실거래로 넘어가는 품질 게이트

### 병행 성과 자격 트랙 — L1 자본 확대 전

아래 성과 게이트는 L0의 5만 원 손실 한도 실험을 막는 조건이 아니라, 전략을 검증됐다고 표시하거나 L1 이상으로 자본·자율성을 확대하기 위한 조건이다.

- 데이터 시점이 주문 가능 시각보다 이후인 미래 데이터 사용 0건
- 배당·분할·상장폐지·종목코드 변경을 반영한 조정 데이터
- 최소 5년, 상승·하락·횡보 국면을 포함한 검증
- 워크포워드 OOS 기간 최소 2년, 역사적 거래 최소 100건
- 모든 비용 차감 후 OOS 초과수익 양수, Sharpe 0.8 이상
- Deflated Sharpe Ratio의 유의 확률 95% 이상
- OOS 최대 낙폭이 해당 모드 중지선 이내: 집중투자 30%, 안전투자 12%
- 핵심 파라미터를 ±20% 변경해도 순기대값 양수

### R0 → L0

- 수익성 OOS 게이트 미통과를 화면과 승인문에 명시하고 5만 원 전액 손실 가능성을 소유자가 확인
- 유효한 결정론적 전략 버전과 공식 시세가 존재
- 신호 재실행 일치율 99.9% 이상
- 주문·체결·잔고 대사 성공률 100%
- 위험 한도 우회·중복 주문·잘못된 종목 주문 0건
- 장애 복구, 토큰 만료, 네트워크 단절, 부분 체결, 거래정지 훈련 통과
- `릴리스 점검` 통과와 사용자의 실거래 활성화 승인

### L0 15일 리뷰와 60일 v2

- 15·30·45거래일 종료 후 실제 체결, 비용, 슬리피지, 손익, 낙폭, 위험 차단, 장애, 그림자 대비 차이를 동결한다.
- 버그·운영·위험 변경은 v1.x로 새 버전을 만들고 다음 거래일부터만 적용한다. 과거 결과를 새 규칙으로 덮어쓰지 않는다.
- 진입·청산·종목선정 논리를 바꾸는 버전은 챌린저로 등록하고 기존 챔피언과 분리해 기록한다.
- 60거래일 종료 시 v1.0~v1.n의 버전별 성과와 전체 운영 증거로 v2 후보를 생성한다.
- v2 생성은 자동 적용·자동 증액을 뜻하지 않는다. 별도 OOS·릴리스 점검과 소유자 승인을 거쳐야 한다.

### L0 → L1

- 60실거래일 보고서와 15일 단위 버전별 계보가 완성돼야 한다.
- 병행 성과 자격 트랙, 실제/그림자 대사, 비용·슬리피지와 위험 게이트를 통과해야 한다.
- v2 후보 또는 유지할 v1.x를 소유자가 지정하고 새 10만 원 위임장을 승인해야 한다.

### L1 이후

- 중대 사고 1건이면 즉시 R0 또는 L0 수동 전용으로 강등
- 실제 슬리피지 20거래 중앙값이 백테스트 가정의 1.5배를 넘으면 신규 진입 중지
- 20회 이동평균 거래 기대값이 음수이면 전략 중지
- 고점 대비 손실 단계는 [RISK_MANDATE.md](./RISK_MANDATE.md)를 그대로 적용

## 주문 전 결정론적 검사

모든 항목이 참일 때만 주문을 생성한다.

1. 전략 버전, 근거 스냅샷, 승인 단계와 주문 목적이 존재한다.
2. 계좌, 시장, 거래일, 거래시간, 종목 상태와 허용 종목군이 맞는다.
3. 실시간 호가가 15초 이내이고 잔고 스냅샷이 30초 이내다.
4. 주문 후에도 현금, 총노출, 시장·종목·섹터·테마·환율 한도를 지킨다.
5. 가격이 마지막 정상 호가에서 3% 이상 벗어나지 않고 주문 금액·수량이 비정상 임계값을 넘지 않는다.
6. 동일 전략·종목·방향·거래일의 멱등 키가 이미 사용되지 않았다.
7. 데이터 장애, 잔고 불일치, 토큰 오류, 킬 스위치가 없다.

검사 결과가 불확실하거나 외부 API가 모호한 응답을 주면 주문하지 않는 `fail closed`를 기본으로 한다.

## 주문 방식 기본값

- L0 자동 위임에서는 별도 단일 실행 워커만 주문을 제출한다. 자동 승인 행위자, 주문안
  범위 해시, 만료, 제출·응답을 모두 감사 원장에 기록한다.
- 뉴스 감시 비신선, 계좌 대사 차이, 오래된 호가, 런타임 미복구, 킬 스위치 또는 브로커
  응답 불명이 있으면 신규 자동 주문을 중지한다. `UNKNOWN` 주문은 절대 자동 재전송하지 않는다.
- L1에서는 가격 제한 없는 시장가 주문을 금지하고 지정가만 사용한다. 긴급 위험축소도 마지막 정상 호가와 가격 보호폭을 둔 시장성 지정가로 제출한다.
- 집중투자 주문 가능 창은 다음 거래일 09:05~09:10, 종가매매는 KRX 거래일 15:20~15:27로 제한한다.
- 전일 신호 종가 대비 3% 초과 상승 갭은 취소한다. 1~3% 갭은 수량을 50% 줄인다.
- 지정가는 신호 종가의 1% 위를 넘지 않는다. 주문 가능 창 안에 체결되지 않은 잔량은 취소한다.
- 부분 체결은 체결분만 포지션으로 인정하고 잔량을 자동 재주문하지 않는다.
- API가 증권사 서버에 보관되는 손절 주문을 지원하지 않으면 GUARDIAN이 실시간 가격을 감시해 위험축소 주문을 제출한다. 연결이 끊기면 손절이 보장되지 않으므로 즉시 경고하고 신규 주문을 차단한다.
- 매도 우선순위는 `오류·킬 스위치 → 손실 한도 → 전략 무효화 → 시간 청산 → 리밸런싱` 순이다.
- KRX 종가 단일가 주문은 `CLOSE-AUCTION-KR-v2` 미션에서만 허용하고 다른 전략 주문안으로 전환하지 않는다.
- 미국 시장은 거래소 현지 시간과 공식 캘린더를 사용하고 서머타임 시간을 코드에 고정하지 않는다.

## 미국 주식과 환전

- 한국 L2 승격 전에는 미국 주문을 비활성화한다.
- 미국도 별도의 연구·OOS·L0·L1 게이트를 통과한다. 한국 성과를 미국에 그대로 이전하지 않는다.
- USD 현금은 미국 목표 노출의 105%까지만 보유한다.
- 자동 환전은 하루 1회, 승인된 미국 주문에 필요한 부족액과 5% 완충분만 허용한다.
- 환율 방향을 예측한 투기성 환전은 금지한다.
- 원화 기준 전체 손익과 현지통화 주식 손익, USD/KRW 환율 손익을 분리 기록한다.

## 자격증명과 권한

- 개발·그림자·실거래 환경의 키와 계좌 식별자를 분리한다.
- 실거래 키는 주문·조회에 필요한 최소 권한만 사용하며 출금·이체 기능은 서비스에 연결하지 않는다.
- 비밀값은 저장소, 프롬프트, 보고서, 로그에 기록하지 않는다.
- 전략 에이전트와 LLM은 자격증명에 접근하지 못한다.
- 주문 조정자 하나만 키움 세션과 주문 권한을 소유한다.
- 모든 수동 개입, 승인, 중지, 재개는 사용자·시각·이유와 함께 감사 원장에 남긴다.

## 대사와 장애 대응

- 주문 제출 직후 접수 번호를 확인하고, 미수신·시간 초과 응답은 조회로 상태를 확정하기 전 재전송하지 않는다.
- 주문 창 동안 60초마다 미체결·체결·가용현금을 대사한다.
- 장 종료 후 주문 원장, 증권사 체결, 계좌 잔고, 내부 포지션을 전부 대사한다.
- 한 항목이라도 불일치하면 다음 신규 주문을 차단한다.
- 킬 스위치는 사용자 UI, 운영자 명령, 자동 위험 규칙 세 경로에서 작동해야 한다.
- 시스템 중지는 무조건 시장가 청산을 뜻하지 않는다. 신규 주문을 막고, 보유 포지션은 유동성과 가격 충격을 고려한 승인된 위험축소 계획으로 처리한다.

- [키움 REST API 이용안내](https://openapi.kiwoom.com/intro/serviceInfo): 계좌 개설, 서비스 신청, 약관 확인 절차
- [키움 REST API 가이드](https://openapi.kiwoom.com/guide/apiguide): 운영·모의 도메인, OAuth와 주문 API 범주
- [KRX 한국 주식시장 거래 가이드](https://global.krx.co.kr/contents/GLB/01/0109/0109000000/guide_to_trading_in_the_korean_stock_market.pdf): 종가 단일가와 시장 안정화 장치
- [FINRA 알고리즘 매매 통제 지침](https://www.finra.org/rules-guidance/key-topics/algorithmic-trading): 개발·시험·검증·운영 후 검토 원칙
- [SEC Market Access Rule 설명](https://www.sec.gov/rules-regulations/2011/06/risk-management-controls-brokers-or-dealers-market-access): 사전 자본 한도, 오류 주문 차단, 권한 제한, 사후 보고 원칙

FINRA와 SEC 규칙은 MoneyGun 개인 사용자에게 직접 적용되는 의무라고 단정하지 않는다. 자동주문 안전 통제의 보수적인 설계 참고 기준으로 사용한다.
