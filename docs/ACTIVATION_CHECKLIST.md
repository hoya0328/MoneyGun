## 1. 키움에서 사용자가 직접 해야 하는 일

1. 키움 REST API 포털에 로그인하고 `API 사용신청`을 완료한다.
2. 사용할 PC 또는 서버의 공인 IP를 등록한다.
3. 신한은행 연계 키움 계좌를 선택하고 계좌 비밀번호·SMS 인증으로 등록한다.
4. `DESKTOP_LIVE`에서는 실전 조회·주문 App Key/Secret과 24자 이상 소유자 토큰을 `.env`가 아니라 `scripts/Set-DesktopLiveSecrets.ps1`로 현재 Windows 사용자에게 암호화해 저장한다.
5. 키움은 등록 계좌의 실전 App Key/Secret으로 조회와 주문 토큰을 발급한다. Signal Guild는 프로세스 격리를 위해 조회·주문 값을 각각 **명시적으로** 입력하며 자동 복사하거나 fallback하지 않는다.

Signal Guild는 사용자의 결정에 따라 모의투자 키를 사용하지 않는다. 모든 운영 관문을 통과하기 전까지 `KIWOOM_TRADING_ENABLED=false`를 유지한다.

## 2. DESKTOP_LIVE 설치 순서

비밀값은 터미널에 표시되지 않는다. 아래 첫 명령에서 사용자가 키움 조회 App Key/Secret, 주문 App Key/Secret, 기억할 수 있는 24자 이상 소유자 토큰을 차례로 입력한다.

```powershell
.\scripts\Set-DesktopLiveSecrets.ps1
.\scripts\install-desktop-live.ps1 -RegisteredPublicIp "키움에 등록한 공인 IPv4"
```

설치기는 Windows 10 Home에서도 동작하도록 SQLite 백업을 소유자 토큰 기반 AES-256-GCM으로 자동 암호화한다. 프로덕션 웹 빌드, 로그인 후 자동 시작 예약 작업과 30초 감시 Supervisor를 만들고 즉시 시작한다. 자동 Windows 업데이트를 끄거나 공유기 포트를 열지 않는다.

운영센터에서 다음 순서로 진행한다.

1. `안전 백업 만들기`
2. `복구 훈련`
3. 그림자 주문 화면에서 소유자 토큰 입력
4. `기동 후 복구 대사`
5. `check-live-readiness.ps1`과 별도 `릴리스 점검`

절전·Windows Time·등록 IP·백업 암호화·24시간 백업 중 하나라도 미통과면 UI에 첫 차단 이유가 표시되고 실주문은 발생하지 않는다.

## 3. 첫 연결 검증

키 입력 후 비밀값을 출력하지 않는 시작 스크립트로 API를 재시작한다.

```powershell
.\scripts\start-api.ps1
```

웹 `그림자 주문` 화면에서 아래 순서로 확인한다.

1. `상태 새로고침`에서 키 준비됨 확인
2. `계좌 동기화` 성공
3. 실제 국내 종목코드 6자리로 `공식 시세 저장` 성공
4. `계좌 대사` 결과 확인

이 단계에서는 릴리스 승인 플래그와 실거래 활성화 플래그를 켜지 않는다.

## 4. L0 시작과 확대 승격

- 키움 `ka10081` 공식 수정주가 일봉을 내부 연구 전용 스냅샷으로 수집한다.
- OpenDART 키를 로컬 `.env`에만 넣고 공시·재무 시점 검사를 실행한다.
- L0는 수익성 미검증·5만 원 전액 손실 가능성을 명시하고 운영·보안·주문 릴리스 관문을 통과하면 시작할 수 있다.
- 5만 원보다 큰 L1로 확대할 때는 OOS AND 게이트, 60일 증거, v2 후보와 새 위임장 승인이 모두 필요하다.
- 테스트 DB를 수정하거나 합성 기록을 넣어 승격 조건을 우회하지 않는다.

현재 `POINT_IN_TIME_DYNAMIC_UNIVERSE-v3` 결과는 집중투자 거래 0건, 종가매매 116건·순수익 54.1%·Sharpe 0.641·MDD -36.44%다. 두 전략은 확대 자격이 없으며 L0에서는 반드시 `수익성 미검증`으로 표시한다.

운영센터의 `실거래 활성화 센터`는 L0와 세 확대 미션의 통과 수, 차단 사유와 다음 단계를 표시한다. 이 조회 자체는 주문을 전송하지 않는다.

## 금지 사항

- App Key, Secret, 계좌번호, 비밀번호, SMS 인증번호를 채팅에 전송하지 않는다.
- 코드의 자동 fallback을 추가하거나 키 값을 채팅·Git에 노출하지 않는다. `DESKTOP_LIVE` 비밀은 Windows DPAPI 파일에서만 로드한다.
- 운영 배포·주문 키·release-candidate 점검 전에 `KIWOOM_TRADING_ENABLED=true`로 바꾸지 않는다.
- 자동 매매용으로 신용·미수·공매도·시장가·파생상품 권한을 사용하지 않는다.
