## 릴리스 승인 뒤에도 유지할 실거래 차단

1. **소유자 실거래 잠금**: `KIWOOM_TRADING_ENABLED=false`, L0 제어 단계 `R0`를 유지한다. 릴리스 승인만으로 주문을 허용하지 않으며 소유자의 별도 최종 확인 뒤에만 `R0→L0`와 거래 플래그를 순서대로 적용한다.
2. **주문별 승인 잠금**: L0 주문 의도가 생겨도 5분 유효 범위 해시와 소유자 토큰 승인이 없으면 브로커 제출을 거부한다.
3. **시장·호가·대사 잠금**: 주문창, 최신 공식 호가, 5만 원 한도, 미체결/계좌 대사를 주문 제출 직전에 다시 검사한다.

## 허용 가능한 L0 위험과 후속 개선

- 전략 OOS 성과는 미통과다. L0는 이를 숨기지 않고 `수익성 미검증·5만 원 전액 손실 가능`으로 표시하며, L1 증액은 계속 금지한다.
- 백업은 같은 시스템 드라이브에 있어 DB 손상 복구에는 유효하지만 PC 분실·디스크 전체 고장에는 부족하다. 암호화 외장 매체 복제는 후속 권장사항이다.
- 외부 클라우드 오류감시 대신 로컬 회전 로그와 앱 운영센터를 사용한다. 원격 알림·무인 L2 운용은 이번 무과금·루프백 L0 범위 밖이다.
- 2.54MB 픽셀 오피스 PNG는 로컬에서는 수용 가능하지만 후속 최적화 대상으로 남긴다.
- Starlette TestClient의 `httpx2` 전환 deprecation warning 1건은 테스트 전용이며 런타임 오류가 아니다.
