# MoneyGun 아트 바이블

최종 갱신: 2026-08-31
상태: MVP UI 디자인 기준 v0.1

## 1. 시각적 방향

MoneyGun의 화면은 카지노나 밈 트레이딩 앱이 아니라 **작은 자본을 정밀하게 운용하는 야간 투자 작전실**처럼 보여야 한다.

핵심 인상:

- 공격적이되 들뜨지 않음
- 어둡고 정밀하며, 증거와 위험이 전면에 보임
- 가상 직원들이 살아 움직이지만 캐릭터 놀이보다 업무 상태가 명확함
- 100배 목표는 동기를 주되 손실 가능성과 같은 시각적 무게를 가짐

금지 인상:

- 슬롯머신, 폭죽, 로켓, 현금비, 승리 애니메이션
- 수익률만 크고 손실 예산은 숨기는 화면
- 빨강·초록만으로 매수·매도·안전·위험을 구분
- 에이전트를 실존 전문가처럼 오인하게 하는 사실적 인물 사진

색상 대비는 WCAG 2.2 AA를 충족하고 상태에는 항상 아이콘, 레이블과 패턴을 함께 사용한다.

### 타이포그래피

- UI 본문: `Pretendard`, 시스템 sans-serif 대체
- 숫자·가격·시간: tabular numerals가 있는 동일 sans-serif
- 제목: 700, 본문: 400~500, 상태: 600
- 가격 숫자에 장식용 monospace를 남용하지 않는다.

기본 크기:

- Display 32/40
- H1 24/32
- H2 20/28
- Body 15/24
- Meta 13/20
- Minimum 12/18

### 형태

- 카드 반경 12px, 버튼 10px, 상태 pill 999px
- 그림자보다 1px 테두리와 표면 명도 차이로 계층 표현
- 8px 공간 단위, 화면 좌우 여백 mobile 16px / tablet 24px / desktop 32px
- 정보 밀도가 높은 표는 행 높이 44px 이상

## 3. 정보 위계

모든 주요 화면은 다음 순서를 지킨다.

1. 지금 주문 가능한가: `NORMAL`, `DEGRADED`, `HALTED`
2. 손실 가능 범위: 미션 자본, 노출, 열린 위험, 중지선
3. 현재 행동: 승인 대기, 주문 중, 대사 실패
4. 왜 행동하는가: 찬성 근거, 반대 근거, 무효화 조건
5. 성과: 목표 사다리, 수익률, 벤치마크, 비용

수익보다 시스템 상태와 위험이 위에 놓인다.

## 4. 핵심 화면

### 4.1 Mission Cockpit

데스크톱 12열 기준:

- 상단 전체: 시장·브로커·데이터·킬 스위치 상태바
- 좌측 7열: 미션 순자산 곡선과 목표 사다리
- 우측 5열: 현재 노출, 열린 위험, -20%·-30% 거리, 이익 금고
- 하단 좌측: 오늘의 투자위원회 결정
- 하단 우측: 직원 상태와 최근 사고

목표 사다리는 7개 명확한 단계로 표현하고, 달성하지 않은 단계는 과장된 빛 효과 없이 윤곽선만 사용한다. 같은 영역에 `최대 손실 가능: 미션 자본 전액` 문구를 고정한다.

### 4.2 Investment Committee

- 후보별 100점 점수와 결정론적 구성요소
- BULL과 BEAR를 좌우 대칭 카드로 배치
- 중앙에 ACE 제안과 RISK 판정
- 모든 주장 옆에 근거 수, 기준 시각, 원문 링크
- 직원의 confidence는 작은 보조 지표이고 주문 크기로 오인되지 않게 표시

### 4.3 Order Approval Sheet

모바일 우선 전체화면 sheet:

- 종목·시장·주문 방향
- 주문 예정 금액과 미션 비중
- 계획손실 원화와 퍼센트
- 진입 가격 범위·무효화 가격·승인 만료
- BULL 핵심 3개와 BEAR 핵심 1개
- `승인`과 `거부`를 같은 시각적 무게로 배치
- 위험도가 높을수록 승인 버튼을 강조하지 않음

### 4.4 Agent Office

직원별 상태를 고유한 픽셀 캐릭터, 담당 방, 책상 소품과 말풍선으로 표현한다. 캐릭터는 친근한 이해 보조 수단이며 투자 성과나 모델 능력을 과장하는 연출에는 사용하지 않는다.

- `WORKING`, `WAITING`, `DONE`, `ABSENT`, `CONFLICT`, `FAILED`
- 현재 작업, 사용 데이터 시각, 마지막 결과, 정확도·근거 품질 추세
- BULL/BEAR 충돌은 해결되지 않은 상태 그대로 보존
- 사무실 공간은 `데이터 창고 → 뉴스·공급망·차트 → 토론 테이블 → 리스크 통제실 → 포트폴리오실 → 주문 금고` 순서로 읽힌다.
- 캐릭터를 선택하면 별명·담당 구역·현재 작업·짧은 설명 말풍선을 표시한다.
- 실제 주문 상태는 캐릭터 감정이 아니라 기존 상태 배지와 시스템 배너가 최종 사실 원천이다.

### 4.4.1 Pixel Office 시각 규칙

- 특정 상용 게임의 캐릭터·타일·UI를 복제하지 않는 MoneyGun 고유 16-bit-inspired 픽셀 스타일
- 깊은 남색 밤 배경, 따뜻한 나무·램프, acid-lime 업무 동선, amber 경고, coral 위험 강조
- 픽셀 원화는 공간과 직원 이해에 사용하고 숫자·표·주문 정보는 선명한 일반 UI 레이어로 분리
- 직원의 낮은 대비 2-step bob만 허용하며 자동 이동, 확률형 보상, 코인·폭죽·로켓 연출 금지
- 모바일은 전체 사무실을 축소 표시하고 상세 말풍선과 업무 단계는 별도 읽기 영역으로 보장

### 4.5 Audit & Incident

- 결정→승인→주문→체결→대사를 시간선으로 표시
- 변경 전·후 hash와 버전
- 사고 심각도, 영향 금액, 자동 조치, 재개 승인
- 삭제·편집 CTA 없음. 정정은 새 이벤트로 추가

## 5. 반응형 규칙

| 범위 | 레이아웃 | 주요 행동 |
|---|---|---|
| `<768px` | 1열, 하단 탐색 4개 | 감시·승인·킬 스위치 |
| `768~1199px` | 8열, 축약 사이드바 | 보고서·포지션 관리 |
| `>=1200px` | 12열, 고정 사이드바 | 전체 연구·설정·감사 |
| `>=1600px` | 최대 콘텐츠 1520px | 표와 비교 패널 확장 |

모바일 하단 탐색은 `Cockpit`, `Committee`, `Orders`, `More`다. 전략 편집·모드 변경·자격증명 관리는 데스크톱에서만 허용한다. 모바일은 읽기·승인·거부·중지에 집중한다.

## 6. 컴포넌트 규칙

### 공통 상태

모든 데이터 컴포넌트는 다음 상태를 구현한다.

- `loading`: 마지막 정상값이 있으면 skeleton 대신 시각과 함께 유지
- `empty`: 데이터 없음과 수집 실패를 구분
- `stale`: 마지막 정상 시각과 주문 영향 표시
- `degraded`: 일부 기능 사용 가능 범위 명시
- `halted`: 원인, 자동 조치, 재개 조건 표시
- `error`: 사용자 행동 가능 여부와 correlation ID 표시

### 주요 컴포넌트

- `SystemStatusBar`: 시장·브로커·데이터·감사·킬 스위치
- `MissionCapitalCard`: seed, equity, exposed, reserved, loss budget
- `GoalLadder`: 1x~100x 진행률과 잠금 이익
- `RiskGauge`: 퍼센트뿐 아니라 원화 손실 한도
- `AgentStatusCard`: 역할, 상태, 기준 시각, 근거 품질
- `EvidenceChip`: 출처 종류, 게시 시각, 검증 상태
- `DecisionCard`: Buy/Hold/Sell과 무효화 조건
- `ApprovalSheet`: 범위 hash와 만료 포함
- `OrderTimeline`: 내부 상태와 키움 상태 구분
- `KillSwitch`: 항상 같은 위치와 형태, 활성 상태는 화면 전체 상단에 유지

## 7. 접근성

- 모든 기능은 키보드만으로 수행 가능
- 포커스 링 2px 이상, 배경 대비 3:1 이상
- 표는 모바일에서 의미 단위 카드로 변환하고 가로 스크롤만 강요하지 않음
- 차트는 요약문과 데이터 표 제공
- 가격 상승·하락은 색, 화살표, 부호와 텍스트를 함께 사용
- 자동 갱신 영역은 스크린리더에 과도한 알림을 보내지 않음
- 킬 스위치와 주문 승인은 44×44px 이상 터치 영역
- `prefers-reduced-motion`을 존중

## 8. 모션

- 일반 전환 150ms, 패널 220ms, 최대 300ms
- 실행 중인 직원은 1.5초 이하의 낮은 대비 pulse만 사용
- 체결은 짧은 행 강조와 상태 변경으로만 표현
- 목표 사다리 달성 시 폭죽·카운트업·진동 금지, 잠금 이익과 새 위험 예산을 함께 표시
- `HALTED`는 깜빡이지 않고 고정된 위험 배너 사용
- 실시간 가격 변화는 300ms 배경 tint 후 원상복귀하며 숫자 이동 애니메이션 금지

## 9. 문구 원칙

- “확실”, “필승”, “대박”, “무조건”, “AI가 예측” 금지
- “매수 추천” 대신 “승인 대기 주문 계획”
- “손절 보장” 대신 “계획 무효화 가격, 갭 발생 시 손실 확대 가능”
- “100배 달성 가능” 대신 “100배 장기 도전 목표, 원금 전액 손실 가능”
- 오류는 기술 코드보다 결과를 먼저 설명: “키움 주문 상태를 확인할 수 없어 재주문을 막았습니다.”
