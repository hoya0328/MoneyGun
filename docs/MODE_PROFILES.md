# MoneyGun 운용 모드 설계

최종 갱신: 2026-09-02
상태: v0.2 · 5만 원 L0 공통 실행 계약 구현

## 모드의 의미

모드는 에이전트의 말투를 바꾸는 프롬프트가 아니다. 허용 전략, 자본, 종목군, 집중도, 거래당 위험, 보유기간, 손실 중지선과 이익 보존 규칙을 함께 고정한 **버전형 투자 위임장**이다.

- 하나의 `투자 미션`은 하나의 모드 버전에 고정된다.
- 포지션이 열린 상태에서 모드를 즉시 변경할 수 없다.
- 모드 변경은 기존 미션 종료 또는 포지션 이전 계획과 사용자 재승인을 요구한다.
- 권한 단계(R0~L3)와 모드는 별개다. 실제 적용 한도는 `권한 단계 한도`와 `모드 한도` 중 더 엄격한 값이다.

## 1. 집중투자 모드 — `FOCUS`

### 컨셉

잃어도 생활에 영향을 주지 않는 작은 독립 자본으로 높은 상승 잠재력을 찾고, 소수의 강한 후보에 집중해 복리 성장을 시도한다. 초기 대표 미션은 **10만 원에서 시작해 1,000만 원을 장기 도전 목표로 표시**한다.

100배는 제품의 보장 수익률이나 승격 기준이 아니다. 미션의 비대칭 목표이며 성공확률, 예상 기간과 최대 손실을 함께 표시한다.

### 기본 한도

| 항목 | 기본값 |
|---|---:|
| 초기 미션 자본 | 100,000원 |
| 외부 추가입금 | 자동 금지, 새 미션으로만 가능 |
| 총 주식 노출 | 최대 100% |
| 보유 종목 | 1~3종목 |
| 단일 종목 | 최대 50% |
| 거래당 계획손실 | 미션 순자산의 최대 5% |
| 전체 열린 위험 | 미션 순자산의 최대 15% |
| 하루 신규 진입 | 최대 1종목 |
| 기본 보유기간 | 2~15거래일 |
| 시장 약세 시 총노출 | 최대 50% |
| 당일 손실 -10% | 다음 세션 신규 진입 금지 |
| 고점 대비 -20% | 거래당 위험 2.5%로 축소 |
| 고점 대비 -30% | 미션 정지·사용자 재승인 |

손실 제한 주문이 갭·거래정지 때문에 계획 가격에 체결된다는 보장은 없다. 운영 중지선은 -30%지만 격리된 미션 자본 10만 원 전체가 손실될 가능성까지 화면에 표시한다.

### 최초 전략군

확대 운용 연구 전략 `FOCUS-MOMENTUM-KR-v1`과 별도로, 5만 원 L0 실험 전략
`FOCUS-MOMENTUM-KR-v2-L0`를 사용한다.

- 15:35~18:00 키움 전시장·완료 일봉 스캔, 다음 거래일 09:05~09:10 지정가
- 가격 2,000~45,000원, 시가총액 500억 원 이상, 20일 중앙 거래대금 50억 원 이상
- 20·60일 추세, KODEX 200 대비 60일 상대강도, 거래량, ATR, 60일 고가권을 채점
- 75점 이상, 계획 손실 최대 1,500원, 최대 45,000원·1종목, 달력 14일 검토
- 5% 상승 뒤 최고가 대비 2% 하락 시 청산 후보를 만든다.
- OOS 수익성 자격을 뜻하지 않으며 확대 자본에는 사용할 수 없다.

기존 `FOCUS-MOMENTUM-KR-v1`은 다음 조건을 사용한다.

- KOSPI·KOSDAQ 보통주, 상장 252거래일 이상
- 20일 중앙 일거래대금 50억 원 이상
- 1주 가격이 현재 단일 종목 주문예산 이내
- 관리·환기·거래정지·정리매매·SPAC·우선주·레버리지 상품 제외
- 가격 추세·상대 모멘텀 40점
- 실적 가속·DART 공시·공급망 촉매 30점
- 최소 재무 품질 10점
- 손실 대비 기대 상승 비대칭 10점
- 유동성·갭·이벤트 안전성 10점
- 75점 이상 중 상위 1~3개만 후보
- 최초 무효화 거리 6~10%, 최소 기대 보상 3R
- 손실 포지션 추가매수 금지, 이익 포지션만 1회 추가 가능

확정 수치는 백테스트 전 운영 전략이 아니며 모든 시도와 변경을 연구 원장에 기록한다.

### 목표 사다리와 이익 금고

미션 화면은 `10만 → 20만 → 50만 → 100만 → 250만 → 500만 → 1,000만` 사다리를 사용한다.

- 각 사다리 달성은 수익 보장이 아니라 이미 실현된 순자산 기록이다.
- 새 최고 사다리를 달성할 때 직전 사다리 이후 실현이익의 20%를 `이익 금고` 현금으로 잠근다.
- 잠긴 현금은 총 미션 순자산에는 포함되지만 자동 주문 예산에서는 제외된다.
- 사용자가 명시적으로 해제하지 않는 한 손실 만회를 위해 다시 투입하지 않는다.
- 100배 진행률과 함께 현재 미션이 0원이 될 수 있는 손실 예산을 같은 크기로 표시한다.

## 2. 종가매매 모드 — `CLOSE_AUCTION`

상태: `CLOSE-AUCTION-KR-v2` R0 챌린저, 현재 OOS 자격 미달

전일 확정 일봉으로 후보를 만들고 다음 거래일 KRX 종가 단일가에 지정가로 진입한다. 최대 1종목·노출 50%·거래당 위험 2%·열린 위험 5%·고점 대비 -15% 중지를 사용한다. 상세 점수, 시간문, OOS 결과와 승격 조건은 [CLOSE_AUCTION_STRATEGY.md](./CLOSE_AUCTION_STRATEGY.md)에 고정한다.

## 3. 장초돌파 모드 — `OPENING_RANGE`

상태: `OPEN-RANGE-KR-v2` 확대 챌린저 미자격, `OPEN-RANGE-KR-v3-L0` 실험 경로 구현

시가 형성 직후 10분을 관찰하고, 시장 방향·VWAP·상대 거래량·유동성이 확인된 장초 범위 돌파만 09:10~10:30에 거래한다. `+1.5R`부터 부분익절과 고점 추적을 사용하고, 당일 `+5%` 신규진입 중단·`+10%` 추적 강화·`+15%` 수익 잠금을 적용한다. 하루 최대 3회, 한 번에 한 종목, 11:00 전 전량청산을 기본으로 한다. “매일 수익”이나 무제한 단타가 아니라 비용 차감 후 양의 기대값과 하루 손실 제한을 목표로 한다. 상세 기준은 [OPENING_RANGE_STRATEGY.md](./OPENING_RANGE_STRATEGY.md)에 고정한다.

v3-L0는 08:50 감시목록, 09:00~09:10 키움 체결·호가·VI 누적, 09:10 이후
현재 완성 1분봉 신호, 11:00 강제청산 후보를 연결한다. 과거 장초 10분 중앙 거래대금이
아직 없으므로 20일 중앙 일거래대금의 10%를 보수적 프록시로 쓴다. 이 프록시는 L0에서만
허용하며 2년 시점고정 분봉 OOS를 대신하지 않는다.

## 4. 안전투자 모드 — `BALANCED`

상태: `BALANCED-TREND-KR-v1-L0` 5만 원 실험 경로 구현, 확대 운용 미자격

| 항목 | 기본값 |
|---|---:|
| 총 주식 노출 | 최대 60% |
| 보유 종목 | 6~12종목 |
| 단일 종목 | 최대 10% |
| 거래당 계획손실 | 최대 0.5% |
| 전체 열린 위험 | 최대 4% |
| 기본 보유기간 | 10~60거래일 |
| 고점 대비 -8% | 신규 진입 중지 |
| 고점 대비 -12% | 모드 정지 |

기존 `QMB-EOD-KR-v1`을 이 모드의 첫 챔피언 후보로 이동한다.

L0에서는 작은 자본 때문에 분산 한도를 구현할 수 없으므로 공통 1종목 한도가 우선한다.
시가총액 3,000억 원, 중앙 거래대금 100억 원, ATR 3.5% 이하, 20·60·120일 정배열,
벤치마크 대비 60일 상대강도 조건으로 80점 이상만 후보가 된다. 다음 장 09:05 지정가,
달력 90일 검토, +10% 활성화 뒤 고점 대비 4% 추적 청산을 사용한다.

## 5. 장기투자 모드 — `LONG_TERM`

상태: `LONG-TREND-KR-v1-L0` 5만 원 실험 경로 구현, 확대 운용 미자격

| 항목 | 기본값 |
|---|---:|
| 총 주식 노출 | 최대 80% |
| 보유 종목 | 5~10종목 |
| 단일 종목 | 최대 15% |
| 현금 최소 | 20% |
| 검토 주기 | 월간, 분기 실적 후 |
| 기본 보유기간 | 6개월 이상 |
| 매수 기준 | 품질·가치·장기 성장·경영진 자본배분 |
| 청산 기준 | 투자 논리 훼손, 재무 안전성 악화, 과도한 가치평가 |
| 고점 대비 -20% | 전체 논리 재심사, 자동 물타기 금지 |

장기투자 모드는 단기 가격 손절을 기본으로 하지 않지만 자본잠식, 회계 신뢰성, 유동성, 포트폴리오 손실 한도는 그대로 적용한다.

현재 L0 경로는 시가총액 1조 원, 중앙 거래대금 200억 원, ATR 3% 이하,
60·120·200일 정배열과 상대강도로만 기술적 후보를 만든다. 달력 365일 검토와
+20% 활성화 뒤 고점 대비 7% 추적 청산을 적용한다. 시점고정 재무·가치·경영진
자본배분 데이터가 아직 결합되지 않았으므로 이를 완전한 장기 품질전략으로 부르지 않으며,
확대 운용 전 OpenDART 시점고정 재무 OOS가 별도로 필요하다.

## 5만 원 L0 공통 실행 계약

- 네 진입 전략과 종가매매는 모두 `mission_l0_pilot_001` 자본 원장으로만 주문한다.
- MoneyGun 실체결 BUY로 생긴 수량만 관리·매도하며 기존 계좌 보유종목은 계속 제외한다.
- 최대 실제 주문 45,000원, 동시 관리 종목 1개, 하루 신규 진입 3회,
  당일 -1,500원·누적 -5,000원에서 신규 매수를 중지한다.
- 모든 주문은 15초 이내 공식 호가, 30초 이내 PASS 대사, 5분 범위 소유자 승인,
  Guardian의 제출 직전 재검사를 통과해야 한다.
- 스케줄러는 후보·주문 의도·청산 의도까지만 만들고 자동 승인·자동 제출하지 않는다.

## 권한 단계와 모드의 결합

| 권한 단계 | 모든 모드에 적용되는 추가 제한 |
|---|---|
| R0 연구 | 주문 없음 |
| R1 그림자 | 주문 없음, 실제 호가로 가상 체결 |
| L1 승인형 | 총노출 최대 50%, 하루 신규 1건, 모든 매수 사용자 승인 |
| L2 제한적 자율 | 선택 모드의 전체 한도 사용, 승인 전략만 자동 주문 |
| L3 정상 자율 | 여러 미션·시장 운용 가능, 모드 간 자본 이동은 사용자 승인 |

## 모드 공통 금지 규칙

- 신용·미수·레버리지·공매도·파생상품
- 자동 추가입금과 은행 계좌 출금
- 손실 포지션 물타기 또는 손실 만회 목적의 위험 확대
- 한 미션의 손실을 다른 미션·이익 금고 자금으로 자동 보전
- 에이전트가 모드·위험 한도·전략 버전을 스스로 변경
- 목표 진행률을 높이기 위한 거래비용·세금·미실현 손실 제외
