# MoneyGun 프로젝트 컨텍스트

최종 갱신: 2026-09-02

## 한 문장 정의

MoneyGun은 작은 독립 자본에서 비대칭 상승 기회를 찾는 투자 미션을 여러 가상 직원이 조사·반론·검증·실행·감사하는 **공격형으로 시작해 여러 운용 모드로 확장되는 개인용 AI 투자회사 운영체제**다.

## 제품 방향

### 주 사용자

- 자기 자본을 운용하는 서비스 소유자 1명
- 리서치 아이디어는 많지만 이를 매일 같은 기준으로 조사·검증·기록·실행하기 어려운 개인 투자자

### 핵심 문제

개인 투자자는 뉴스, 공급망, 실적, 차트, 시장 심리와 위험을 동시에 추적하기 어렵고, 좋은 아이디어도 명시적인 규칙과 검증 가능한 기록으로 바꾸지 못해 감정적·비일관적 의사결정을 반복한다.

### 사용자가 고용하는 일

> 내가 정한 투자 원칙과 위험 한도 안에서, 가상 투자회사가 매일 근거를 수집하고 서로 반박하며 재현 가능한 결정을 만들고, 검증 게이트를 통과한 전략은 내 계좌에서 안전하게 실행·대사·학습하게 해 달라.

### 가치 제안

- 단일 AI의 즉흥 추천이 아니라 역할이 분리된 투자위원회가 결론을 만든다.
- 모든 수치와 주장은 시점이 고정된 데이터와 출처에 연결한다.
- 전략 아이디어를 자연어에서 검증 가능한 규칙으로 변환한다.
- 리서치와 주문 사이에 독립적인 위험 심사와 결정론적 통제 장치를 둔다.
- 잘된 판단뿐 아니라 틀린 판단과 규칙 위반도 기억해 다음 의사결정에 반영한다.
- 작은 미션 자본은 계좌의 다른 현금과 논리적으로 격리해 최대 손실 범위를 먼저 고정한다.
- 집중투자·종가매매·장초돌파·안전투자·장기투자를 말투가 아니라 서로 다른 버전형 위임장으로 제공한다.

## 서비스 원칙

1. **증거 우선**: 출처·기준 시각·데이터 버전이 없는 주장은 주문 근거가 될 수 없다.
2. **반론 의무화**: 매수 논리에는 반드시 반대 논리와 무효화 조건이 붙는다.
3. **LLM과 주문 권한 분리**: AI 직원은 조사·요약·제안을 담당하고, 수량·한도·주문 가능 여부는 결정론적 규칙이 계산한다.
4. **초소액 실거래 학습**: 연구 결과가 수익성을 보장하지 않는다는 사실을 명시한 채, 기술·보안 릴리스 게이트를 통과하면 5만 원으로 60거래일 L0 실거래 파일럿을 시작한다. 같은 신호의 그림자 쌍을 항상 병행하고, 더 큰 자본과 자율성은 품질 게이트를 건너뛸 수 없다.
5. **조용한 자기변경 금지**: 직원이 새 규칙을 제안할 수는 있지만 운영 전략을 스스로 수정하거나 승격할 수 없다. 모든 전략은 버전과 승인 기록을 가진다.
6. **재현 가능성**: 같은 데이터 스냅샷과 같은 규칙으로 결론·백테스트·주문 계획을 다시 만들 수 있어야 한다.

## 기본 사용자 여정

1. 소유자가 투자 원칙, 위험 한도, 관심 테마와 외부 인사이트를 등록한다.
2. 장 종료 후 DATA가 가격·거래량·재무·뉴스를 시점 고정 스냅샷으로 만든다.
3. NOVA, SERENITY, PULSE가 독립적으로 후보와 근거를 제출한다.
4. BULL과 BEAR가 같은 후보를 두고 논쟁하고, 빠진 데이터와 무효화 조건을 명시한다.
5. RISK가 포트폴리오 전체 위험과 주문 가능 범위를 계산한다.
6. ACE가 매수·매도·보류 중 하나를 결정하고 근거·반론·확신도·보유 기간을 기록한다.
7. OPS가 현재 승격 단계에 따라 그림자 주문, 사용자 승인 주문 또는 자동 실주문을 실행하고 예상 대비 체결 차이를 대사한다.
8. GUARDIAN이 API·잔고·손실·중복 주문 상태를 감시하며 이상 시 신규 주문을 중지한다.
9. AUDIT가 결과를 전략·직원·시장 국면별로 평가하고 개선 제안을 전략 후보 큐에 넣는다.

## MVP 가설

역할이 분리된 증거 기반 의사결정, 결정론적 위험·주문 통제와 단계적 승격을 사용하면, 단일 AI 추천이나 즉흥 수동 매매보다 더 일관되고 감사 가능하며 재현 가능한 실거래 프로세스를 만들 수 있다.

## MVP 결과

5만 원으로 시작하는 한국 주식 L0 초소액 실거래 미션과 같은 신호의 그림자 원장을 60거래일 동안 함께 운영한다. 15실거래일마다 실제 체결·손익·위험·운영 지표를 검토해 v1.1~v1.n 개선안을 만들고, 60일 종료 시 전체 증거를 기반으로 v2 후보를 만든다. v2와 자본 확대는 자동 적용하지 않고 별도 검증·릴리스 점검·소유자 승인을 거친다. 안정성이 입증되면 10만 원 승인형과 제한적 자율 실거래로 승격하고, 안전투자·장기투자와 미국 주식을 후속 모드·시장으로 추가한다. 매 거래일 다음을 완성한다.

- 시점 고정 데이터 스냅샷
- 출처가 연결된 후보 종목과 찬반 논쟁
- 위험 한도를 통과한 매수·매도·보류 결정
- 다음 세션의 단계별 모의·실제 주문과 체결·잔고 대사
- 포지션·손익·의사결정 계보와 사후 검토

## MVP 기능

### P0 — 반드시 포함

- 투자 위임장: 허용 시장, 종목군, 최대 포지션, 최대 손실, 금지 조건
- 투자 미션과 모드: 10만 원 격리 자본, 목표 사다리, 이익 금고, 집중투자 모드 버전
- 인사이트 원장: 링크/메모를 주장·근거·검증 상태·적용 후보로 구조화
- 시점 고정 데이터 스냅샷과 데이터 품질 검사
- 명시적 조건식으로 실행되는 종가 후보 스캐너
- 산업/공급망, 거시/뉴스, 퀀트/기술 분석 보고서
- BULL/BEAR 논쟁과 독립 위험 거부권
- 버전이 있는 전략 명세 및 비용·슬리피지를 포함한 워크포워드 검증
- 그림자 주문, 체결·잔고 대사, 즉시 중지 스위치
- 키움 실거래 어댑터, 사전 주문 검사, 멱등성, 부분 체결과 장애 복구
- 연구→5만 원 L0 실거래+동시 그림자→10만 원 승인형 실거래 승격 게이트
- 일일 브리핑, 근거 계보, 직원·전략별 점수표

### P1 — MVP 검증 후

- 안전투자·장기투자 모드 활성화
- 장초돌파 모드의 2년 분봉 OOS와 60거래일 실시간 그림자 자격 증거
- 한국 L2 이후 분리된 미국 주식 연구·그림자·실거래 슬리브
- Kronos 같은 가격 시계열 모델을 챌린저 신호로 비교
- skfolio 기반 포트폴리오 최적화 후보 비교
- 복수 전략의 자본 배분과 국면별 가중치
- 모바일 모니터링과 이상 알림

## 명시적 비목표

- 첫날부터 무인 완전자율·전액 실거래
- 10만 원→1,000만 원의 성공확률·기간·수익률 보장
- 밀리초 고빈도·호가 선점·무제한 틱 스캘핑 전략
- 암호화폐, 파생상품, 공매도, 레버리지 동시 지원
- 한국·미국 시장을 첫날부터 동시에 완전자율 운용하거나 여러 증권사를 동시에 지원
- 공개 투자자문, 타인 자금 운용, 종목 추천 판매
- 수익률 보장 또는 릴스의 수익 사례 재현 약속
- LLM이 계산한 가격·재무 수치를 검증 없이 사용
- 처음부터 오픈소스 프레임워크 전체를 결합하는 대형 통합

## 성공 지표

### 북극성 지표

**거래비용 차감 정보비율(Information Ratio)**: 실거래 전에는 워크포워드 OOS, 실거래 후에는 실제 체결 손익으로 운영 전략의 벤치마크 대비 초과수익을 추적오차로 나눈다. 단기 절대수익이 아니라 재현 가능한 위험 조정 초과성과를 본다.

집중투자 미션의 제품 진행률은 100배 목표 사다리로 보여주지만 북극성 지표를 대체하지 않는다. `미션 자본 밖 손실 0원`과 `자동 추가입금 0건`은 절대 안전 지표다.

### 지원 지표 및 초기 품질 게이트

- 데이터·근거·규칙·결정·주문까지 연결된 의사결정 비율: 100%
- 미래 데이터 누출 및 잘못된 종목 식별 사고: 0건
- 위험 한도 위반 주문: 0건
- 승인된 모의·실제 주문과 체결·잔고 대사 성공률: 100%
- 전략 재실행 시 신호 일치율: 99% 이상
- 최대 낙폭, 회전율, 슬리피지, 집중도: 위임장 한도 이내
- 직원 보고서의 출처 누락률과 반론 누락률: 각각 0%

단계 승격에 필요한 수익·위험 최소치는 정했지만 수익률 보장 목표는 두지 않는다. 실제 자본 입력 후에도 한도를 완화하지 않고 주문 가능 금액만 계산한다.

실거래 승격의 수치 기준과 단계별 권한은 [LIVE_TRADING_POLICY.md](./LIVE_TRADING_POLICY.md), 초기 집중투자 기준은 [MODE_PROFILES.md](./MODE_PROFILES.md), 후속 안전투자 전략은 [STRATEGY_BASELINE.md](./STRATEGY_BASELINE.md)를 따른다.

## 초기 시장·벤치마크 방침

- 운영 순서: **한국 주식 먼저, 미국 주식 두 번째**. 미국 연구·그림자 운용은 한국 품질 기록 후 시작할 수 있지만 미국 실주문은 한국 L2 승격 전까지 비활성화한다.
- 증권사 통합 후보: 키움증권 REST API. 공식 안내상 국내주식과 미국주식을 모두 지원하며 운영·모의 서버가 분리되어 있다.
- 한국 슬리브 벤치마크: KOSPI 200 총수익지수. 코스닥 중심 전략은 KOSDAQ 150 총수익지수를 보조 벤치마크로 함께 기록한다.
- 미국 슬리브 벤치마크: S&P 500 Total Return.
- 통합 벤치마크: 원화 기준 `한국 70% + 미국 30%` 혼합 벤치마크. 주가 선택 효과와 USD/KRW 환율 효과를 별도로 귀속한다.
- 실제 거래비용은 키움 계좌에 적용되는 수수료·세금·환전 스프레드를 설정값으로 저장하고, 고정된 오래된 세율을 코드에 박아 넣지 않는다.

세부 위험 수치는 [RISK_MANDATE.md](./RISK_MANDATE.md)에 수정 가능한 기본안으로 기록한다.

## 현재 가정

- 개인 1인용 비공개 서비스다.
- L0 5만 원 파일럿은 별도 클라우드 서버 없이 소유자의 Windows PC를 단일 전용 호스트로 사용하는 `DESKTOP_LIVE` 운영 프로필을 우선한다. 이 프로필은 외부 인바운드와 모바일 원격 접속을 열지 않으며, PC 전원·절전·네트워크·시간·키움 인증·계좌 대사 중 하나라도 불확실하면 신규 주문을 차단한다.
- AWS와 관리형 클라우드는 L0 필수조건이 아니다. 원격 접속, 다중 장치, L2 무인운용, 더 높은 가용성 또는 자본 확대가 필요할 때 별도 비용·보안·릴리스 결정을 거쳐 도입한다.
- 초기 제품 컨셉은 잃어도 생활에 영향을 주지 않는 10만 원 독립 미션으로 높은 상승 잠재력을 추구하는 집중투자 회사다.
- 데스크톱에서 연구·설정하고 모바일에서는 상태와 경고를 확인한다.
- 장 종료 후 일봉 중심의 저빈도 전략을 먼저 운영하고, 장초돌파는 별도 분봉 데이터 관문을 통과한 뒤 독립 미션으로 추가한다.
- 첫 검증 기간은 기술·보안 릴리스 게이트를 통과한 뒤 5만 원 L0 실거래와 동일 신호 그림자 운용을 병행한다. 전략 성과 미검증 상태이며 5만 원 전액 손실 가능성을 전제로 한다.
- 최종 제품에는 사용자의 키움 계좌에서 제한적 자율·정상 자율 실거래가 포함된다.
- 초기 투자 테마는 Serenity 자료와 연결되는 AI·반도체 공급망을 우선 후보로 삼되, 시장 전체 유동성 필터를 둔다.
- 한국·미국 주식을 모두 운용하되 한국 시장의 검증과 단계별 실거래 승격을 먼저 완료한다.
- 키움증권을 첫 증권사로 사용하고 신한은행 연계 계좌를 이용한다.
- 키움 공개 문서에 신한은행 연계 계좌의 API 적격 여부가 명시되어 있지 않으므로, 해당 키움 계좌의 HTS ID 연결·해외주식 거래 신청·REST API 등록 가능 여부를 별도 확인한다.

- MoneyGun 전용 키움 계좌를 추가로 사용할 수 있는지 여부. 불가능하면 내부 미션 원장으로 10만 원을 격리한다.
